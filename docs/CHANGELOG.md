# Changelog

## 1.5.6

- 正式切换为 Release 商店构建：debuggable=false、R8、资源压缩、APK+AAB。
- OCR 从 bundled 中文模型切换到更小的离线 Latin 模型，降低安装包体积。
- 图片健康历史改为基于 OCR 坐标逐行解析，修复容量/循环次数跨行串值。
- 每条截图记录独立识别 OS3/OS4 系统版本，不再复用第一条版本。
- Bugreport 与当前设备增加 HyperOS 系统版本识别。
- 移除未使用依赖并只保留 arm64 + 中英文资源。

## v1.5.5 — 2026-09-12
- 将此前 v1.5.4 UI/报表增强修订正式提升为独立版本号，避免同版本不同 versionCode 带来的安装与识别混淆。
- 保留“热爱生活·为您充电！”新版首页、精简卡片说明、报表三指标顶部 UI、系统相册图片导入、多条健康历史截图识别与“一键查找最新报告”。
- 保留 HyperOS 3/4 Bugreport 多来源解析、超级岛 10 秒节流/通知缺失恢复策略、统一通知 #1 与固定签名方案。
- 版本更新为 1.5.5，versionCode 15；沿用现有 BATTERYKEEPER_* Repository Secrets，可从固定签名的 v1.5.3+ 正常覆盖升级。

## v1.5.4 — 2026-09-12
- 概览页标语更新为“热爱生活·为您充电！”，移除卡片底部重复说明文案。
- 报告页顶部改为最新健康报告三指标 UI（健康度/满充容量/循环次数）。
- 图片导入改用系统 Photo Picker/相册，并支持图表式健康历史截图的一图多条识别。
- 新增“一键查找最新报告”：首次通过 SAF 授权错误报告目录，后续自动扫描最新 ZIP。

- 超级岛普通刷新降至 10 秒；功率变化 ≥ 3W 或温度变化 ≥ 1℃ 时允许提前刷新，电量/插拔/状态变化立即刷新。
- 只有统一通知 #1 真正不存在时才自动恢复，不再因为焦点 extras 瞬时读取不到而高频补发。
- 设置页诊断拆分为 BatteryKeeper 应用侧与 HyperOS/SystemUI 两层，并明确个人自用、未配置 App ID 时无法保证视觉层长期常驻。
- 修复部分 Xiaomi 内核 `CURRENT_NOW` 充电符号相反导致本次充电的已充入、平均功率、峰值功率长期为 0；内部功率方向统一为充电正、放电负。
- 充电协议分档改用功率幅值，避免负号导致快充错误识别为普通充电。
- Bugreport ZIP 导入升级为 HyperOS 3/4 多来源解析：AIDL HealthInfo > Health HAL > POWER_SUPPLY_* > batterystats，并统一 uAh/mAh。
- 报告导入预览与历史记录显示解析格式、字段来源和置信度。
- 版本保持 1.5.4，UI/报表增强修订 versionCode 14，沿用 v1.5.3 固定签名 Secrets 与单通知 #1 架构。

## v1.5.0 — 2026-09-12

- 移除 v1.4 `TYPE_APPLICATION_OVERLAY` 仿超级岛和 `SYSTEM_ALERT_WINDOW` 权限。
- 新增 `XiaomiIslandController`，通过 `Notification + miui.focus.param` 接入 Xiaomi HyperOS 3 原生超级岛。
- 原生岛仅在充电时存在；拔电、停止充电、关闭功能或停止监测服务时立即取消。
- 岛内不提供 Action；点击通知/岛直接打开 BatteryKeeper 主界面。
- 新增 HyperOS 超级岛协议版本、系统支持状态和焦点通知权限检测。
- 更新节流策略：电量/充电档位变化立即刷新；功率变化 ≥ 1W 或温度变化 ≥ 1℃ 时最低 4 秒刷新一次。
- 保留 v1.4.0 的 Bug Report 大文件解析与导入修复。

# 更新记录

## v1.4.0 — 2026-09-12

### 新增

- 充电会话周期检查点与最近充电记录。
- 历史区间纯计算模块及 6 项回归测试。
- 报告识别结果预览、手动校正、去重校验和删除确认。
- 分页 CSV 导出、小组件点击打开应用、数据来源提示。

### 修改

- 首页改为先展示实时电量、功率和温度，再展示健康数据。
- 趋势页以今天零点为“今日”，按实际观测时长统计。
- Room 注解处理从 kapt 切换到 KSP。
- 中文离线 OCR 升级至 16.0.1。
- 提高正文对比度与常用字号。
- 悬浮胶囊改为仅充电时显示。

### 修复

- 修复毫秒时间戳转换为 Float 导致曲线横轴丢失精度。
- 修复放电积分逐次取整导致循环估算长期偏低。
- 修复健康估算只存在内存、满充后不稳定刷新的问题。
- 修复今日统计结束充电后不能及时刷新和进行中会话重复计算。
- 修复按样本数量计算放电时间占比的偏差。
- 修复日统计跨日、平均温度越界和采样空缺外推问题。
- 修复循环次数使用隐藏属性而漏掉 Android 14 公开字段。
- 修复 OCR 健康度不能识别小数及识别器未关闭。

### 兼容性

- 保持包名、原签名证书和 Room v2 结构不变，可覆盖 v1.3.0 并保留数据。
- 仅支持 Android 14+ 的 arm64 设备。


## 1.5.1
- 原生超级岛生命周期改为以物理电源连接 (`plugged != 0`) 为准，避免 HyperOS 暂停充电时几秒后错误下岛。
- 显式设置焦点通知 12 小时、岛 12 小时生命周期，并保持 `dismissIsland=false`。
- 摘要态大岛改为左侧温度（1 位小数，℃）、右侧功率。
- 展开态补充电量、充电档位、功率、温度、电压、电流；不添加 Action，二次点击进入主界面。
- 电源连接期间使用充电采样频率，即使系统暂时报告 NOT_CHARGING 也持续更新。

## 1.5.3
- 设置页版本号改为读取安装包实际 versionName，避免再次出现界面版本与 APK 版本不一致。
- 超级岛说明文案同步为“连接电源时常驻 / 点击摘要态展开 / 再点击进入主界面”。
