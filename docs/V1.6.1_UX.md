# BatteryKeeper v1.6.1 UX

- App icon redesigned with a slimmer battery silhouette and blue/white palette; Android 13+ monochrome themed icon added.
- Static launcher shortcuts: system battery settings, toggle monitoring, import health screenshot, recent charge records.
- Dashboard cards use weighted full-height layout to remove lower whitespace; today-charge card shows charged mAh, session count, and current-session peak.
- Charts page uses weighted full-height cards so power, temperature, and summary fill the viewport.
- Bottom icon-only navigation height adjusted from 54dp to 60dp.
