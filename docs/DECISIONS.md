# 技术决策

## 2026-09-12：在现有工程上重构

- 问题：原版已有可用导入、数据库、小组件和 UI 基础，但统计与状态语义存在问题。
- 选择：保留包名、数据库结构和签名兼容性，重写关键计算与页面信息层级。
- 原因：可覆盖安装并保留用户历史数据。
- 缺点：部分旧模型字段仍保留，以维持二进制与数据库兼容。

## 2026-09-12：功率定义为电池侧估算

- 选择：使用公开 `BATTERY_PROPERTY_CURRENT_NOW × EXTRA_VOLTAGE`，界面统一标注“电池侧功率”。
- 原因：第三方应用无法可靠读取小米充电协议和协商功率。
- 缺点：数值包含手机自身负载，不等同于充电器输出。

## 2026-09-12：循环读取使用公开广播字段

- 选择：Android 14+ 优先读取 `BatteryManager.EXTRA_CYCLE_COUNT`，不再反射不存在或不稳定的隐藏属性。
- 缺点：设备厂商可能仍不提供有效值，需要报告或安装后估算兜底。

## 2026-09-12：按时间积分并忽略长空缺

- 选择：电量积分保留小数；相邻采样超过 120 秒视为未知区间；统计按区间交集和时长加权。
- 原因：避免整数截断、不同采样频率和服务中断导致系统性偏差。
- 缺点：覆盖不足时统计值只代表已观测时段。

## 2026-09-12：Room 代码生成切换为 KSP

- 选择：KSP 2.0.21-1.0.28 + Room 2.6.1。
- 原因：与 Kotlin 2.0.21 匹配，并避免 kapt 在当前构建环境的路径解析问题。
- 影响：构建需要 KSP 插件；数据库结构未变化。

## 2026-09-12：保留离线 OCR

- 选择：ML Kit 中文 OCR 16.0.1 随 APK 打包。
- 原因：报告截图不上传，离线可用；该版本原生库支持 16 KB 页面对齐。
- 缺点：APK 约 18.9 MB。

## 2026-09-12：签名材料不进入源码包

- 选择：交付 `keystore.properties.example`，排除真实 keystore 和密码。
- 原因：私钥泄露将永久破坏更新链安全。
- 影响：已有已签名 APK 可直接安装；自行构建签名版需单独保管原签名材料。
