# 已知问题与平台限制

- 尚未完成小米 17 / 澎湃 OS 4 真机测试，后台存活和自启动受系统省电策略影响。
- 实时功率是电池侧估算，包含手机自身负载，不能代表充电器输出、协议名称或协商功率。
- 系统循环字段由厂商决定是否上报；无值时只能依赖报告或安装后的放电累计估算。
- `CHARGE_COUNTER` 是否可用及其精度由设备燃料计决定；满充容量估算可能无法生成。
- 悬浮胶囊是普通系统悬浮窗，不是澎湃 OS 原生“上岛”；位置需按目标机型真机调整。
- 桌面小组件是标准 Android AppWidget，不能进入小米原生小组件体系。
- OCR 依赖截图清晰度和页面文案，已增加保存前校正，但仍需用户核对。
- APK 仅包含 arm64-v8a，不支持 x86/x86_64 模拟器和非 arm64 设备。
- Release Lint 当前为 0 error、45 warning；警告主要涉及依赖更新、硬编码文本、仅 arm64 与悬浮窗内部状态栏尺寸读取。
- 微软雅黑等商业字体未随应用打包。
