# v1.5.1 原生超级岛接入说明

BatteryKeeper v1.5.1 延续 v1.5 的 Xiaomi HyperOS 原生超级岛，并针对真机测试优化生命周期与摘要态布局。

## 生命周期

`BatteryMonitorService -> XiaomiIslandController -> Notification + miui.focus.param -> HyperOS SystemUI`

- 连接电源（`plugged != 0`）：创建/保持岛通知。
- 充电中：同一 notification id 更新，最低 5 秒刷新一次温度/功率。
- HyperOS 因满充保护、温控、旁路供电等把状态短暂切为 `NOT_CHARGING` 时，不再错误下岛。
- 真正拔掉电源、关闭原生岛或停止监测服务：取消岛通知。
- `param_v2.timeout = 720 min`，`islandTimeout = 43200 s`，`dismissIsland = false`。
- 小米准入原则要求单次持续服务生命周期不超过 12 小时，因此不做无限时长岛。

## 摘要态

目标布局：

`温度  ← 摄像头/岛中心 →  功率`

实际用短文本以符合摘要态字数规范：

`38.1℃  ← 摄像头 →  32W`

- A 区：`imageTextInfoLeft(type=1)`，显示温度。
- B 区：`textInfo`，显示功率。
- 小岛兜底：BatteryKeeper 电池图标。

## 点击交互

不提供底部 Action。

HyperOS 原生交互目标：

1. 点击摘要态：由 SystemUI 展开主要信息。
2. 展开态显示：充电档位、电量、功率、温度、电压、电流。
3. 再点击展开态：通过 Notification `contentIntent` 打开 `MainActivity`。

## 备注

大岛/小岛切换以及展开态约 5 秒后自动收起属于 HyperOS SystemUI 原生行为，应用只能提供模板内容和生命周期参数，不能强制展开态永久停留。
